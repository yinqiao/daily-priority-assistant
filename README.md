# 🎯 技能简介：你的智能工作助理
**每日工作优先级助手**是一款专为飞书用户设计的智能工作流辅助技能。它通过聚合您在飞书生态中的多源工作数据，结合预设的智能排序算法，为您生成一份简洁、聚焦的今日工作优先级清单。
在快节奏的研发与产品工作中，我们常常面临**工作碎片化**、**优先级混乱**、**多数据源切换频繁**以及**时间管理困难**等挑战。该技能的核心价值在于，它能够自动完成信息的收集与初步分析，将您从手动梳理会议、待办、文档、消息的繁琐过程中解放出来，直接呈现需要优先关注的核心事项。
本技能尤其适合**产品研发和工程架构部门**的同事，以及任何需要同时处理多个项目、任务，并希望将有限精力精准投入到最重要工作上的员工。
# 💡 核心功能：数据聚合与智能排序
技能的核心在于其**全自动的数据聚合能力**与**基于多维度权重的智能排序逻辑**。

# 🚀 快速开始：三步上手
1. **首次配置（关键一步）**首次使用时，技能会向您询问：“为了帮你更好地对齐优先级，请提供你的 OKR 文档链接（飞书云文档）”。**您必须提供一个有效的飞书云文档链接**，这是技能判断任务与您的核心目标（OKR）对齐度的唯一依据，对排序结果有决定性影响。
1. **日常触发**配置完成后，您可以在任何需要的时候，使用自然的对话语句触发技能。例如：
  - “帮我看一下今天的优先级”
  - “我今天该先做什么？”
  - “整理一下今天的工作”
  - “事情太多了帮我排一下优先级”
  - “重新整理一下优先级”
1. **获取结果**触发后，技能将自动执行以下流程：实时收集上述五大来源的数据 → 基于您的 OKR 和六维算法进行智能分析与排序 → 在几秒内生成并输出一份清晰的优先级清单。

# 📝 注意事项与FAQ
### 注意事项
1. **OKR文档是核心**：首次使用**必须**配置有效的飞书OKR文档链接，否则技能无法进行目标对齐度分析，排序准确性将大幅降低。
1. **基于实时数据**：每次调用技能，它都会重新拉取最新的日历、待办、消息等数据。这意味着清单反映的是**当前时刻**的最新情况。
1. **简洁输出原则**：技能设计初衷是“减负”而非“增负”，因此会主动过滤信息，只输出最精要的结论。如需查看某类任务的完整列表，请直接访问对应的飞书应用。
### 常见问题 (FAQ)
**Q1: 如何更新或更改已配置的OKR文档？**A: 只需在下次触发技能时，主动告知新的文档链接即可，例如：“更新我的OKR文档，链接是：[新文档链接]”。技能会记住最新的配置。
**Q2: 我觉得排序结果不符合我的个人判断，怎么办？**A: 技能的排序是基于通用规则和您提供的OKR。您可以将最终决策权掌握在自己手中。输出清单是**建议**，您可以根据实际情况调整执行顺序。同时，确保您的OKR文档和飞书任务标签（如紧急/重要）是准确且最新的，这能帮助技能更好地理解您的意图。
**Q3: 技能会访问和存储我的哪些数据？安全吗？**A: 技能仅在您单次会话请求时，临时访问您授权的飞书日历、待办、文档等数据以生成清单。**所有数据处理均在当次会话中完成，不会存储任何您的个人任务数据或OKR内容**。其数据访问范围与权限和您手动打开这些飞书应用是一致的，符合 ByteDance 的数据安全规范。
**Q4: 技能能识别我所有自定义的飞书多维表格吗？**A: 技能可以访问您有权限且已关联的飞书多维表格。为了获得最佳效果，建议您将核心的项目任务表、需求池等关键表格在飞书中管理好，并确保表格中有清晰的“截止日期”、“负责人”等字段。
